# APEX Racing Club — Formula Racing Website

A responsive, front-end demo website built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run it

1. Extract the ZIP file.
2. Open `index.html` in a recent browser.
3. For best results, serve the folder using any simple local static server (for example, VS Code Live Server).

## What's included

- Responsive homepage and mobile navigation
- Race calendar with Street Circuit / Permanent filters
- Featured race spotlight section
- Original SVG concept-car illustration
- Fictional team and driver cards
- Drivers / teams standings tabs
- Merchandise cards with a working local cart, quantity controls, and subtotal
- Newsletter form with client-side validation
- Accessible labels, keyboard Escape support for cart drawer, and reduced-motion support
- No framework or build process

## Important demo notes

- APEX Racing Club, teams, drivers, and merchandise are fictional concept content.
- Calendar entries, season figures, and standings are sample data and are not official live information.
- The cart is local to the browser. Checkout does not take payment or submit an order.
- The newsletter form validates input only; it does not send or store email addresses.
- The hero and race-spotlight photos load from Unsplash and require an internet connection. If the hero photo cannot load, the included original APEX concept-car SVG provides a local visual fallback. The concept car and favicon are included in `assets/`.
- Google Fonts are used for display typography. If unavailable, system fallback fonts are used.
- This is an independent fan concept and is not affiliated with Formula 1, its teams, or its partners.

## Files

- `index.html` — website structure and page content
- `styles.css` — layout, theme, and responsive breakpoints
- `script.js` — navigation, calendar filters, standings tabs, cart, and form validation
- `assets/concept-car.svg` — original fictional car illustration
- `assets/favicon.svg` — site icon
